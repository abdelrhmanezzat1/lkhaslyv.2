Lakhsly

Ad Hoc build for registered iPhones.

Registered devices only. This app is signed with an Apple Ad Hoc provisioning profile. It installs only on iPhones whose UDID is already included in that profile. Other devices will get an installation error — this is an Apple restriction and cannot be bypassed.
Install Lakhsly

Open in Safari on the registered iPhone. After the first install: Settings > General > VPN & Device Management > trust the developer certificate. Version shown after install comes from the app itself (…).

Need a new device registered? Send its UDID to the maintainer; the provisioning profile is regenerated after each device add.
